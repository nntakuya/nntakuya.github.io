プライバシーポリシー

開発者 nntakuya（以下「開発者」）は、iOS アプリ「登録販売者 一問一答」（以下「本アプリ」）における利用者の情報の取り扱いを、以下のとおり定めます。

1. 開発者が直接集める情報

本アプリにはサーバーもアカウント登録もなく、開発者は氏名・メールアドレス等の情報を集めません。解いた問題・答え・成績の中身も、開発者には送られません（第5項）。

開発者が受け取るのは、アプリの使われ方の統計（購入の画面がどこから開かれたか、購入の件数、利用者数。Firebase が標準で自動的に集める基本の記録を含みます）と、アプリが落ちたときの記録だけです。これらは Google の Firebase を通じて集めます。氏名・メールアドレス・アカウントの情報や、解いた問題・答え・成績の中身は含みません。一方、アプリごとの識別子（アプリのインスタンス ID）は、統計に含まれます。また、購入を終えたとき Firebase が自動で送る記録に、商品の ID・金額・通貨・数量などが入る場合があります（第3項・第6項）。このほか、広告については、Google が集計した広告の数字（表示回数・収益など）を、開発者が AdMob の画面で見ます（第3項）。

ただし、お問い合わせのメールをいただいた場合は、返信のためにメールアドレスと本文を利用します。

2. 外部のサービスの利用

本アプリは、広告の配信と、使われ方の把握・不具合の調査のため、次の外部サービスを組み込んでいます。

  • Google AdMob（広告の配信）：Google LLC が提供します。購入前の無料の利用者に、ホーム・取り違え帳・成績の画面の下にバナー広告を表示することがあります。購入済みで本アプリを開いたときは、広告の部品を呼び出さないため、広告の初期化も広告の要求も行いません。
  • Firebase（Google アナリティクス・Crashlytics）：Google LLC が提供します。使われ方の統計と、落ちたときの記録に使います。本アプリは追跡の許可を求めないため、Google アナリティクスは広告識別子（IDFA）を集めません（第3項）。

購入の支払いは、Apple の App 内課金で行われます。カード番号・Apple ID は、開発者には送られません。購入を終えたとき Firebase が自動で送る記録に、商品の ID・金額・通貨・数量などが入る場合があります。送信される情報の詳細は、第3項の表のとおりです。

4. 広告と追跡の許可（ATT）

本アプリは、iOS の「App Tracking Transparency」の確認画面を表示せず、利用者に合わせた広告（パーソナライズ広告）は配信しません。広告は、利用者に合わせない設定で要求します。Google アナリティクスは、追跡の許可を得ていないため、広告識別子（IDFA）を集めません（第3項）。広告は、購入すると表示されなくなり、購入済みで本アプリを開いたときは、広告の初期化も広告の要求も行いません。

5. 端末内に保存するデータ

学習の記録（解答の結果、間違えた問題、取り違え帳、途中の状況）と、外観の設定、購入済みであることの印は、利用者の端末内にのみ保存し、開発者は受け取りません。本アプリを削除すると、学習の記録は消え、開発者は復元できません。設定の「成績と取り違え帳を消す」で、学習の記録を消すこともできます（購入は消えません）。開発者に送られるのは、第1項・第3項の「使われ方の統計」と「落ちたときの記録」、Google が集計した広告の数字だけです。Google に送られた情報の保持期間は、次のとおりです。Crashlytics の落ちたときの記録（スタックトレースと、それに結びつく識別子）は 90 日間保持されます（https://firebase.google.com/support/privacy）。Google アナリティクスの個別のイベントのデータ（データ探索などで見られるもの）は、開発者の設定により 2 か月または 14 か月です。集計したレポートには、この設定は影響しません（https://support.google.com/analytics/answer/7667196?hl=ja）。アプリを削除すると、新たな送信は止まります。Google が保持する情報については、Google のプライバシーポリシーに従います。

6. 購入の記録

購入の画面の使われ方を知るため、本アプリは、自分で送る記録としては、次の 5 つだけを Firebase に送ります（Firebase が標準で自動的に集める基本の記録は、第3項のとおり、これとは別です）。購入の画面を開いた／閉じた／購入ボタンを押した／購入が完了した／購入の復元で購入済みに戻った。このうち前の 3 つには、画面を開いた入口（章の無料分を使い切ったとき・取り違え帳・無料の問題を一巡したとき・設定のどれか）の名前だけを付けます。本アプリが自分で送る 5 つの記録には、金額、商品の識別子、支払いに関する情報、Apple ID、氏名やアカウントのような利用者の ID は入れていません（アプリのインスタンス ID は、第3項のとおり、Google アナリティクスの記録に付きます）。ただし、購入を終えたとき Firebase が自動で送る記録に、商品の ID・金額・通貨・数量などが入る場合があります（第3項）。購入そのものの処理は、Apple が行います。
